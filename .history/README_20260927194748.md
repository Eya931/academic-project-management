# Academic Project Management

Application de gestion de projets académiques développée avec Spring Boot. Le système permet de gérer les projets, les groupes, les tâches, les livrables, les documents, les utilisateurs et les rôles, avec un accès sécurisé via authentification JWT.

## Objectif

Cette plateforme vise à centraliser la gestion des projets universitaires et pédagogiques en offrant :

- une gestion des utilisateurs et des profils,
- une gestion des projets et des équipes,
- un suivi des tâches et des livrables,
- une gestion des documents associés,
- un système d’authentification et d’autorisations,
- un module d’email et d’activation de comptes.

## Fonctionnalités principales

- Authentification et inscription des utilisateurs
- Gestion des rôles et permissions
- Création et suivi de projets
- Organisation des groupes et équipes
- Attribution des tâches
- Gestion des livrables (PDF, vidéo, liens)
- Stockage et gestion des documents
- Validation des comptes par email
- API REST documentée avec Swagger/OpenAPI
- Sécurité basée sur Spring Security + JWT

## Stack technique

- Java 22
- Spring Boot 3.4.4
- Spring Web
- Spring Data JPA
- Spring Security
- PostgreSQL
- Maven
- Lombok
- Thymeleaf
- JWT (jjwt)
- Springdoc OpenAPI

## Prérequis

Avant de lancer le projet, vérifiez que vous avez :

- Java 22
- Maven ou Maven Wrapper
- PostgreSQL installé et démarré
- Un IDE comme IntelliJ IDEA ou VS Code

## Configuration

Le fichier de configuration principal se trouve dans :

- `project_managment/src/main/resources/application.yml`

Le projet utilise actuellement le profil `dev` et configure le contexte API sur :

- `/api/v1`

## Lancement du projet

Depuis le dossier `project_managment` :

```bash
./mvnw clean install
./mvnw spring-boot:run
```

Sous Windows :

```powershell
mvnw.cmd clean install
mvnw.cmd spring-boot:run
```

## Base de données

Le projet est configuré pour utiliser PostgreSQL. Assurez-vous d’avoir une base de données disponible et de configurer les paramètres de connexion dans les fichiers de configuration Spring.

## Documentation API

Une fois l’application démarrée, la documentation Swagger est accessible à :

```text
http://localhost:8080/api/v1/swagger-ui/index.html
```

## Docker

Un fichier `docker.compose.yml` est présent pour aider à démarrer les services nécessaires au projet. Vous pouvez l’utiliser selon votre environnement local.

## Développement

Le code est structuré en modules fonctionnels par domaine métier, ce qui facilite la maintenance et l’évolution de l’application.

### Domaines principaux

- `auth` : inscription, connexion, sécurité
- `project` : gestion des projets
- `group` : gestion des groupes
- `team` : gestion des équipes
- `task` : gestion des tâches
- `deliverable` : livrables et fichiers
- `documentation` : documents associés
- `role` : rôles et permissions
- `user` : gestion des utilisateurs
- `email` : envoi d’emails et activation de comptes
